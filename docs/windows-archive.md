# Windows archive

The Windows application is archived. The active project and its current
manuals target Linux on RHEL 9; Windows installers, PowerShell administration
and Windows application operating instructions are not current installation
paths.

Historical source and documentation are preserved on the public
[`windows-archive` branch](https://github.com/Halino/lto-archiver/tree/windows-archive).
The historical [`v0.11.27` source tag](https://github.com/Halino/lto-archiver/tree/v0.11.27)
also remains available for reference. Historical Windows ZIP release packages
remain public and immutable, with their original assets preserved and archive
labels. The [archived Windows v0.11.27 release](https://github.com/Halino/lto-archiver/releases/tag/v0.11.27)
is historical material, not the Linux download channel. Do not use a historical
ZIP or the repository's latest-release link to install the Linux application.

Linux-side [import of an existing sealed legacy capture](linux/migration.md)
and portable tape names are compatibility features of the Linux source.
Windows clients can supply SMB data to Linux through supported share settings;
that does not distribute or maintain a Windows archiver application. Historical
Windows-side preparation and operating procedures belong to the archive branch.

Return to the [Linux documentation index](en/index.md),
[current source candidate notes](release-notes-0.11.31-155.md), or
[Linux installation guide](linux/installation-rhel9.md). Linux RPM build,
signing, disposable-host qualification and publication are still pending.
