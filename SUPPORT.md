# Support

## Application support

Use GitHub issues for reproducible LTO Archiver application defects and feature
requests after removing sensitive operational data. For a suspected security
problem, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Include this minimal, sanitized diagnostic information:

- LTO Archiver version and Windows version;
- HPE StoreOpen version and the drive/media generation (not a serial number or
  real media label);
- the exact safe reproduction steps, expected behavior, actual behavior, and
  relevant sanitized error text;
- whether the operation was read-only, privileged, or destructive.

Before attaching anything, remove credentials, tokens, private keys, usernames,
private paths, network addresses, catalog databases, logs containing private
data, operational identifiers, and any HPE support ticket.

## HPE hardware and software support

LTO Archiver is independent of and not affiliated with Hewlett Packard
Enterprise. It cannot provide vendor support for HPE tape drives, libraries,
firmware, device drivers, HPE StoreOpen, LTFS mounting, or HPE Library and Tape
Tools. Use the applicable HPE support channel for those products, media or
hardware faults, and vendor diagnostics. Do not copy an HPE support ticket into
a public issue.
